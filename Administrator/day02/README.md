## What is a Salesforce Report?

A **Salesforce Report** is a structured list of records that meet specific criteria. Reports help users organize, filter, summarize, and analyze Salesforce data to gain business insights.

### Key Features

- Filter records
- Group and summarize data
- Generate charts
- Export data
- Schedule report generation
- Share reports with teams

---

## What is a Salesforce Dashboard?

A **Salesforce Dashboard** is a visual representation of one or more reports. It displays business metrics using charts, graphs, gauges, and tables, allowing managers to monitor organizational performance at a glance.

### Dashboard Components

- Bar Charts
- Pie Charts
- Line Charts
- Tables
- Gauges
- Metrics

---

## Difference Between Reports and Dashboards

| Reports                         | Dashboards                           |
| ------------------------------- | ------------------------------------ |
| Display detailed records        | Display summarized visual data       |
| Used for data analysis          | Used for monitoring KPIs             |
| Can be exported                 | Built using report data              |
| Supports filtering and grouping | Uses charts and visual components    |
| Suitable for operational users  | Suitable for managers and executives |
