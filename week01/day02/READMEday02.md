# 2. Explain App, Object, and Tab

## APP

-- An app is a combination of tabs, objects, designed for a specific task or to complete a job.
e.g:- sales app, client app, data visualization app, college or a branch management app etc are the examples of app.

## Object 

-- object is like a table(details block) in the database to store the user data in it.

examples for an object are : account object, contact object, sales object, transaction object etc...

## Tab 

-- a tab is aworking area where the admin or the assister used to help the user to solve the problem arrived..

examples for tab are , user tab, accounts tab, sales tab etc...

# 3. Difference Between App and Object?.

-- app is a interface for storing the object 
-- object is the data storing place
-- app organises the working area
-- where as the object stores the records
-- app contains tabs, objects, dashboards.
-- object stores fields, records.
